# Laserbeak

Демон + програма для macOS, які показують проєкти й сесії Claude Code та
Codex, сповіщають про їхній стан і дають ними керувати (режим, модель,
стиснення). Плюс розширення браузера, що шле в сесію скріншот зони
сторінки, команди `start`/`stop` і мод, що малює відповіді Claude
картками.

## З чого почати

Читай у такому порядку — цього досить, щоб зрозуміти проєкт:

1. **`docs/architecture.md`** — як усе влаштовано і чому саме так
2. **`docs/components.md`** — що робить кожен файл
3. **`docs/decisions.md`** — здобуті знання й пастки, на які вже наступали
4. **`docs/api.md`** — HTTP-інтерфейс демона

`README.md` — для користувача, не для розробника. Дублює частину docs.

## Частини

```
Claude Code / Codex (сесії)   hooks/hook.sh  →  POST 127.0.0.1:8787
       ↓                      shell/laserbeak.zsh — start / stop (tmux)
   src/*.js                   демон: Node, живе як LaunchAgent
       ↓
   app/macOS/*.swift          програма на маку: вікно, меню-бар, банери
   extension/*.js             розширення браузера: зона на сторінці → сесія
   claude/reply-cards/        мод Claude Code: відповіді картками
```

Телефонної програми й чату з сесією більше немає — їх прибрано свідомо.

## Коли ставиш це комусь

Установка не мовчазна: перед `npm run install:all` **спитай користувача,
якою мовою він хоче Laserbeak** — `uk`, `en`, `cs`, `ru`, `kk` або
`auto` (як у системі). Вибір передається змінною:

```bash
LASERBEAK_LANG=cs npm run install:all
```

Мова одна на все: банери, історія подій, помилки API, **вікно програми,
меню-бар, розширення браузера, `start`/`stop`** і перший запит у сесію.
Вона лягає в `~/.laserbeak/config.json`. Змінити потім — у програмі:
Налаштування → Загальні (вікно перейде на нову мову після перезапуску,
решта — одразу). Без `LASERBEAK_LANG` повторна установка мову не
скидає.

Решта установки автоматична, крім трьох речей, яких зробити не можна:
Xcode з App Store, сертифікат Apple Development (це вікно Xcode із
входом в Apple ID) і завантаження розширення через `chrome://extensions`
— браузер не пускає туди жодне розширення.

### Після установки перевір швидкі команди — їх постійно забувають

Без `start` сесія Claude Code не працює через tmux, а отже Laserbeak не
може передати в неї ні скріншот, ні режим, ні модель. `install.sh`
дописує в `~/.zshrc` один рядок `source …/shell/laserbeak.zsh`.
Перевір, що вийшло:

```bash
zsh -ic 'whence -w start stop'     # start: function / stop: function
```

- Якщо `install.sh` написав «у ~/.zshrc уже є своя start()» — там стара
  копія. Запропонуй користувачу замінити її (разом зі `stop` і `_lb_*`)
  рядком, який він надрукував. Це особистий файл: **без згоди не правити.**
- Якщо оболонка не zsh — скажи про це: `start`/`stop` написані для zsh.
- Скажи користувачу, що команди діють у **нових** вкладках термінала (або
  після `source ~/.zshrc`), і покажи, як запускати: `start "назва"`,
  `start codex "назва"`, `stop`.

### І мод карток

`install.sh` ставить мод `reply-cards@laserbeak` (репозиторій —
маркетплейс із теки, `.claude-plugin/marketplace.json`). Перевір:

```bash
claude plugin list | grep -A2 reply-cards
```

Діє в нових сесіях Claude Code. Якщо `claude` не знайдено — скажи, що
мод не поставлено, і дай команду `claude plugin install reply-cards@laserbeak`.

## Найважливіші правила

**Демон — єдине джерело істини.** Уся логіка й стан там. Програма й
розширення лише показують те, що прийшло з `/state` чи `/settings`, і
надсилають дії. Налаштування теж живуть у демона (`config.json`), а не в
програмі.

**Моделі Swift розбирають JSON вручну.** Swift не підставляє значення за
замовчуванням для відсутнього ключа — кидає `keyNotFound` і валить розбір
усієї відповіді. Додаючи поле в модель, додай його і в `CodingKeys`, і в
`init(from:)` через хелпер `c.value(.key, default)`. Інакше програма
покаже порожній екран.

**Кожен рядок інтерфейсу — усіма п'ятьма мовами.** Пиши в коді
українською, додавай у `app/Resources/Localizable.xcstrings` з `en`, `cs`,
`uk`, `ru`, `kk`. Збірка сама не витягує туди `String(localized:)`. Так
само з `src/i18n.js`, `extension/_locales/*` і таблицею в
`shell/laserbeak.zsh`. Перевірка одна на все:

```bash
npm run check:l10n
```

Один ключ — одне значення: «Оновити» (список) і «Оновити» (версію) — це
різні ключі, бо англійською й чеською це різні слова.

**Хуки мають лишатись тупими.** `hooks/hook.sh` — це лише `curl` на
localhost. Жодної логіки: вона гальмувала б кожну дію в сесії.

**Агентів два: Claude Code і Codex** (`start codex "назва"`). Шлях
спільний — той самий `hook.sh`, у кожної сесії поле `agent`. Те, що
вміє лише Claude (режими Shift+Tab, `/model`, `/effort`), для Codex демон
чесно відмовляє, а програма не пропонує. Хуки Codex потребують
підтвердження в самому Codex — прапорця
`--dangerously-bypass-hook-trust` не використовуй ніде.

**Демон слухає лише 127.0.0.1, і це не налаштовується.** Ключа доступу
немає — він був для телефона. Перевірки стоять одна, на вході в
`src/server.js`: не з цього компʼютера — `403`, сторінка з мережі (за
`Origin`) — `403`. Додаючи маршрут, нічого робити не треба. Єдиний запит
назовні — перевірка оновлень на `api.github.com`, і вона вимикається в
налаштуваннях.

**Браузер — теж клієнт, і найменш довірений.** Розширення в
`extension/` ходить у демон по `127.0.0.1`, тому довіра до localhost
більше не безкоштовна: демон дивиться на `Origin` і відсіює сторінки з
мережі. Але памʼятай, що `POST` зі сторінки долітає без preflight, тобто
**виконується**, навіть коли відповіді ніхто не бачить.

**Програма на маку — не декорація.** Вона — меню-бар і банери з іконкою
проєкту; без неї банери падають на безликий `terminal-notifier`. Тому за
нею стежить `src/appguard.js` і піднімає, якщо та замовкла. `KeepAlive`
у launchd для цього не годиться — там пастка з `open`, описана в
`docs/decisions.md`. Свідомий вихід лишає `~/.laserbeak/app-quit`, і його
треба поважати.

**Нову дію з програми додавай через `client.act(...)`** у
`DaemonClient.swift`, а не власним `URLRequest`.

**Текст у сесію мусить бути однорядковим.** Кожен `\n` — це Enter, тобто
окрема відправка: багаторядковий запит прилетить частинами. Якщо збираєш
текст із чужих шматків (як `shots.js`), проганяй їх через `flat()`.

**Оновлення не чіпає робочу копію, доки його не попросили.** Перевірка
лише читає GitHub API; `git pull` робить тільки кнопка «Оновити»
(`scripts/update.sh`, `--ff-only`). Скрипт запускається відірваним від
демона, бо `install.sh` демон перезапускає.

**Нічиєї особистої тотожності в репозиторії.** Team ID для підпису
береться з того сертифіката, що лежить у зв'язці ключів цієї машини
(`scripts/team-id.sh`), і потрапляє у збірку через `LASERBEAK_TEAM`.
Зашитий у `project.yml` ідентифікатор означав би, що зібрати проєкт може
лише його автор. Готового інсталятора немає навмисно: програму збирають
на тій машині, де нею користуватимуться, — інакше Gatekeeper зустріне її
попередженням, а ad-hoc підпис узагалі позбавляє сповіщень.

## Команди

```bash
npm run install:all     # повна установка (демон, хуки, програма, start/stop, мод)
npm run restart         # перезапустити демон
npm run logs            # хвіст лога
npm run state           # поточний стан у JSON
npm run build:app       # перезібрати програму на маку
npm run extension       # шлях до розширення браузера в буфер
npm run check:l10n      # чи все перекладено всіма мовами
```

Після правок у `src/` демон треба перезапустити: `npm run restart`.
Після правок у `app/` — перезібрати програму. Після правок у
`claude/reply-cards/` — `/reload-plugins` у сесії.

Подивитись програму іншою мовою, нічого не міняючи в налаштуваннях:

```bash
/Applications/Laserbeak.app/Contents/MacOS/Laserbeak -AppleLanguages '(cs)'
```

## Де лежать дані

`~/.laserbeak/` — конфіг, логи, реєстр проєктів, архів, стан оновлень.
Код можна клонувати куди завгодно, дані лишаються на місці.
