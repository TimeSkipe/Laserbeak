# Laserbeak

Демон + застосунки для macOS та iOS, які показують проєкти й сесії
Claude Code, сповіщають про їхній стан і дозволяють писати в них запити.

## З чого почати

Читай у такому порядку — цього досить, щоб зрозуміти проєкт:

1. **`docs/architecture.md`** — як усе влаштовано і чому саме так
2. **`docs/components.md`** — що робить кожен файл
3. **`docs/decisions.md`** — здобуті знання й пастки, на які вже наступали
4. **`docs/api.md`** — HTTP-інтерфейс демона

`README.md` — для користувача, не для розробника. Дублює частину docs.

## Три частини

```
Claude Code (сесії)          hooks/hook.sh  →  POST 127.0.0.1:8787
       ↓
   src/*.js                  демон: Node, живе як LaunchAgent
       ↓
   app/*.swift               програми на маку й телефоні
   extension/*.js            розширення браузера: зона на сторінці → сесія
```

## Коли ставиш це комусь

Установка не мовчазна: перед `npm run install:all` **спитай користувача,
якою мовою він хоче бачити сповіщення** — доступні `uk`, `en`, `cs`, або
`auto` (як у системі). Вибір передається змінною:

```bash
LASERBEAK_LANG=cs npm run install:all
```

Він потрапляє в `~/.laserbeak/config.json` і діє на банери, історію подій
і помилки API. Інтерфейс самих програм цього не стосується — там мова
береться з налаштувань пристрою, тож телефон з англійською системою
покаже англійський екран сам.

Змінити потім: `"language"` у конфігу (перечитується на льоту) або
разово — `LASERBEAK_LANG=en npm start`.

Решта установки автоматична, крім трьох речей, яких зробити не можна:
Xcode з App Store, сертифікат Apple Development (це вікно Xcode із
входом в Apple ID) і завантаження розширення через `chrome://extensions`
— браузер не пускає туди жодне розширення.

## Найважливіші правила

**Демон — єдине джерело істини.** Уся логіка й стан там. Програми лише
показують те, що прийшло з `/state`, і надсилають дії. Ніякої власної
логіки в клієнтах.

**Моделі Swift розбирають JSON вручну.** Swift не підставляє значення за
замовчуванням для відсутнього ключа — кидає `keyNotFound` і валить розбір
усієї відповіді. Додаючи поле в модель, додай його і в `CodingKeys`, і в
`init(from:)` через хелпер `c.value(.key, default)`. Інакше програма
покаже порожній екран.

**Хуки мають лишатись тупими.** `hooks/hook.sh` — це лише `curl` на
localhost. Жодної логіки: вона гальмувала б кожну дію в сесії.

**Демон за замовчуванням не виглядає в мережу взагалі** (`bindHost:
127.0.0.1`). Телефон ходить через програму на маку зашифрованим каналом.
Якщо ввімкнути запасний шлях (`0.0.0.0`), усе, що прийшло не з
`127.0.0.1`, має принести `Authorization: Bearer <ключ>` — інакше `401`.
Додаючи маршрут, нічого робити не треба: перевірка стоїть одна, на вході
в `src/server.js`. А от якщо маршрут щось **створює** на компʼютері, він
має бути `isLocal`-only, як `/sessions/spawn`.

**Програма на маку — не декорація.** Вона тримає єдиний канал до
телефона, тому за нею стежить `src/appguard.js` і піднімає, якщо та
замовкла. `KeepAlive` у launchd для цього не годиться — там пастка з
`open`, описана в `docs/decisions.md`. Свідомий вихід лишає
`~/.laserbeak/app-quit`, і його треба поважати.

**Клієнти не знають, яким шляхом ідуть дані.** Телефон ходить або прямим
зашифрованим каналом до програми на маку, або по HTTP із ключем. Обидва
сховані за `DaemonTransport`. Нову дію додавай через `client.act(...)`,
а не власним `URLRequest` — інакше вона працюватиме лише по HTTP.

**Обгортки над `NWConnection` мусять реагувати на скасування.** Інакше
запит висить вічно, попри таймаут: група задач чекає на дочірню, а та
стоїть на продовженні, яке ніхто не розбудить. Використовуй хелпер
`cancellable` із `PeerLink.swift`. Подробиці — у `docs/decisions.md`.

**Браузер — теж клієнт, і найменш довірений.** Розширення в
`extension/` ходить у демон по `127.0.0.1`, тому довіра до localhost
більше не безкоштовна: демон дивиться на `Origin` і відсіює сторінки з
мережі. Додаючи маршрут, нічого робити не треба — перевірка стоїть одна,
поруч із перевіркою ключа. Але памʼятай, що `POST` зі сторінки долітає
без preflight, тобто **виконується**, навіть коли відповіді ніхто не
бачить.

**Текст у сесію мусить бути однорядковим.** Кожен `\n` — це Enter, тобто
окрема відправка: багаторядковий запит прилетить частинами. Якщо збираєш
текст із чужих шматків (як `shots.js`), проганяй їх через `flat()`.

**Нічиєї особистої тотожності в репозиторії.** Team ID для підпису
береться з того сертифіката, що лежить у зв'язці ключів цієї машини
(`scripts/team-id.sh`), і потрапляє у збірку через `LASERBEAK_TEAM`.
Зашитий у `project.yml` ідентифікатор означав би, що зібрати проєкт може
лише його автор. Готового інсталятора немає навмисно: програму збирають
на тій машині, де нею користуватимуться, — інакше Gatekeeper зустріне її
попередженням, а ad-hoc підпис узагалі позбавляє сповіщень.

**Спільний код у `app/Shared/`** компілюється для обох платформ.
Перевіряй так (збірка під iOS потребує платформи, а перевірка типів — ні):

```bash
SDK=$(xcrun --sdk iphonesimulator --show-sdk-path)
swiftc -typecheck -sdk "$SDK" -target arm64-apple-ios17.0-simulator \
  app/Shared/*.swift app/iOS/*.swift
```

Розміри вікон задавай через `.windowSize(...)`, а не `.frame(minWidth:)` —
на телефоні жорстка ширина виштовхує вміст за екран.

## Команди

```bash
npm run install:all     # повна установка (демон, хуки, програма на маку)
npm run restart         # перезапустити демон
npm run logs            # хвіст лога
npm run state           # поточний стан у JSON
npm run build:app       # перезібрати програму на маку
npm run extension       # шлях до розширення браузера в буфер
bash scripts/install-phone.sh   # зібрати й поставити на iPhone
```

Після правок у `src/` демон треба перезапустити: `npm run restart`.
Після правок у `app/` — перезібрати програму.

## Де лежать дані

`~/.laserbeak/` — конфіг, логи, реєстр проєктів, архів переписки.
Код можна клонувати куди завгодно, дані лишаються на місці.
